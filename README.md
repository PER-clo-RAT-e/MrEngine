# MrEngine

This is customisable game engine for terminal.
You can add games by putting them into the `src/modules/game` foder.
Also, you can add custom menus for it using the `src/modules/engine` folder.

All modules are written in custom DSLs and have specified structure.
Use `.uiscm` files for defining UI and `.loscr` for logic. 

See more in `TheDoc` folder or see the example module in `src/modules/engine/main`
